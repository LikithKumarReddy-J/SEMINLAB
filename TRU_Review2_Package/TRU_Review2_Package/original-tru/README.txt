TRU - 4 MODULE VERSION
========================

This is the same tru project reorganized into 4 modules.

1. Login Module
   login/login.html
   login/login.css
   login/login.js

2. Social Module
   social/social.html
   social/social.css
   social/social.js

3. Discover Module
   discover/discover.html
   discover/discover.css
   discover/discover.js

4. Admin Module
   admin/admin.html
   admin/admin.css
   admin/admin.js

Common runtime:
   common/common.css
   core.js
   runner.js
   index.html

IMPORTANT:
Run index.html with VS Code Live Server (not by double-clicking the HTML file).
The root index loads all four module HTML files and their existing functions work together.
